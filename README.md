# Nam Khanh Nguyen

Source code for my personal website: [khanhnguyen174.github.io](https://khanhnguyen174.github.io/).

The site is built with Jekyll and the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Open <http://localhost:4000> in a browser.
